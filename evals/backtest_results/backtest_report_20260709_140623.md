## Methodology

For each **(model, ticker, cutoff)** the REAL analysis pipeline was run frozen to the cutoff date — **no lookahead**:

- **Prices & technicals**: Yahoo Finance history truncated to on/before the cutoff.

- **News**: only vector-store articles *published ≤ cutoff* (RSS is live-only and cannot be time-travelled).

- **Excluded** (cannot be cleanly reconstructed as-of): SEC filings, FRED macro, and RAG historical context.

- **No DB writes** — backtest runs never touch the live database or vector store.

- The model's **predicted direction** is graded against the **actual close ~7 calendar days later** (BULLISH >+1%, BEARISH <−1%, else NEUTRAL).

- **Reasoning depth** scored 1–5 by a fixed independent LLM judge (deepseek-v4-pro).

- **Cost** = tokens × published price (DeepSeek cache-miss input; Gemma via OpenRouter).
